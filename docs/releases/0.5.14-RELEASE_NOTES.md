# 尖塔全程领航 0.5.14

## 简体中文

- 适配《杀戮尖塔 2》v0.114.0 原版单人游戏，搭配 CombatSolver 1.0.3 和 RitsuLib 0.6.16 或更新的兼容版本。
- F9 接管期间由领航窗口显示当前搜索和出牌进度。F8 的求解器设置支持 1–600 秒战斗求解上限。
- 东尼算法动态牌继续使用游戏 v0.113.x、领航 0.5.13 和兼容版 CombatSolver 0.51.10。

## English

- Supports vanilla single-player Slay the Spire 2 v0.114.0 with CombatSolver 1.0.3 and a compatible RitsuLib version starting at 0.6.16.
- While F9 autopilot is active, the SpireAutopilot overlay shows current search and play progress. The F8 Solver tab supports a combat solve limit of 1–600 seconds.
- For AutoAnthony generated cards, use game v0.113.x, SpireAutopilot 0.5.13, and the CombatSolver 0.51.10 compatibility build.
