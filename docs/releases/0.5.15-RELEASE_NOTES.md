# 尖塔全程领航 0.5.15

## 简体中文

- 改善 GPT、DeepSeek 与 Claude 的自动决策连接：断流、限流和临时服务错误会自动重试，必要时重新发送完整局面。
- 兼容带尾逗号的模型 JSON，执行前核对当前可用动作。
- 支持通过本机 Claude Code 连接兼容网关，并区分账户额度、鉴权和协议错误。
- 药水栏已满时仍可查看奖励药水效果，并选择腾出空位或继续前进。

适配《杀戮尖塔 2》v0.114.0，搭配 CombatSolver 1.0.3 和 RitsuLib 0.6.16 或兼容版本。

## English

- Recover from interrupted requests, temporary service errors and rate limits, rebuilding the complete decision context when needed.
- Accept trailing commas in model JSON and validate each action against the current game state.
- Connect to compatible Claude gateways through the optional local Claude Code transport, with separate billing, authentication and protocol messages.
- Keep potion details available when all slots are filled, so the model can make room or continue.

For Slay the Spire 2 v0.114.0 with CombatSolver 1.0.3 and a compatible RitsuLib version starting at 0.6.16.
