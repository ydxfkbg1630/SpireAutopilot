# 尖塔全程领航 0.5.13

## 简体中文

- 战斗改用领航维护的 CombatSolver 兼容依赖，订阅领航后自动安装。
- 支持 AutoAnthony 0.3.165 动态卡牌的实际效果、选牌、箭矢、费用变化与死亡触发模拟。
- AutoAnthony 已加载时，领航会提示求解器适配状态。

## English

- Combat now uses the CombatSolver compatibility dependency maintained with SpireAutopilot, installed automatically through the Workshop dependency.
- Supports AutoAnthony 0.3.165 generated card effects, card choices, arrows, cost changes, and death triggers.
- SpireAutopilot reports the solver compatibility status when AutoAnthony is loaded.
